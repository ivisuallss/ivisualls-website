# i.visuallss

Mobile-first videography booking website for **i.visuallss** — instant reels, iPhone clips, and event coverage in **Hyderabad, Telangana**.

Bookings are sent directly to WhatsApp — no database or Firebase required.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- React Router (data router)

## Configuration

Edit services, packages, prices, and contact details in:

`src/config/business.ts`

## Development

```bash
npm install
npm run dev
```

